1. WHAT THIS LECTURE COVERS
  - Matrices in Python with NumPy: building them, the convenience
    builders, plotting a matrix as a colored grid, reading its
    shape, pulling out one cell, one row, or one column, and
    getting eigenvalues and eigenvectors with one function call.
  - The programming counterpart to Lectures 7 through 9. Everything
    computed by hand there is one line here.

2. LISTS OF LISTS VERSUS NUMPY ARRAYS
  - Just as with vectors, you could represent a matrix natively as
    a nested list, a list of lists. You will have a much better
    time in the long run using NumPy arrays instead.
  - Same two reasons as Lecture 6 (added): far less code for each
    operation, and far faster on large matrices, because NumPy
    stays down in C instead of looping in Python.
  - The alias is the usual standard:
      import numpy as np

3. BUILDING A MATRIX
  - Write a list containing lists, one inner list per row, and wrap
    it in np.array. NumPy recognizes the nesting as a matrix.
  - Printing it shows the row-by-row grid. Print its type and it is
    not a list, even though it looks like one when printed. The
    type is numpy.ndarray.
  - Higher order matrices, 3 by 3 and up, work the same way: more
    inner lists inside the outer list.
  - Example (added), the 2 by 3 hardware shop matrix from the
    Lecture 7 notes:
      import numpy as np
      M = np.array([[5,1,7],[2,8,3]]) ## two rows, three columns
      print(M) ## [[5 1 7] [2 8 3]]
      print(type(M)) ## <class 'numpy.ndarray'>
    Each inner list is one row. Two inner lists, two rows. Three
    numbers per inner list, three columns.

4. CONVENIENCE BUILDERS: ONES, ZEROS, AND SCALING
  - NumPy has functions for creating a matrix of a given size
    filled with ones, or filled with zeros. Hand them the size as
    rows by columns.
  - The trick the lecture points out: to get a matrix of all fours,
    make a matrix of all ones and multiply it by the scalar 4.
    Scalar times matrix is component-wise, so every one becomes a
    four (added: that is Lecture 3's scaling rule applied to a
    grid).
  - Code (added):
      import numpy as np
      print(np.ones((2,5))) ## 2 by 5 of 1.
      print(np.zeros((4,2))) ## 4 by 2 of 0.
      print(7*np.ones((3,3))) ## 3 by 3 of 7.
    The size goes in as a tuple, (rows, columns), with its own
    parentheses inside the function's parentheses. The values print
    as 1. and 0. with a decimal point because these builders make
    floating point matrices (added).
  - When you would use this (added): a blank grid to fill in later,
    a starting board for a simulation, a mask of ones to switch
    cells on and off, a constant matrix to add to another.

5. LOOKING AT A MATRIX: IMSHOW
  - There are many ways to visualize what a matrix contains. The
    course relies on Matplotlib's pyplot library, aliased plt.
  - The lecture builds a matrix of random numbers drawn uniformly
    between zero and one using NumPy's random number generator,
    then plots it with imshow, the image show function. Each cell
    of the grid is colored according to the number in the matrix.
  - plt.colorbar adds the legend that says which number each color
    corresponds to. Look at a cell's color, look at the color bar,
    read off roughly what number sits in that cell.
  - See the noisy random grid with its color bar in the Lecture 10
    notebook section "Python Programming with Matrices". It looks
    like noise because it is noise.
  - Code (added):
      import numpy as np, matplotlib.pyplot as plt
      M = np.random.random((10,15)) ## 10 by 15, uniform 0 to 1
      plt.imshow(M) ## one colored cell per number
      plt.colorbar() ## which color means which number
    This is the tool the lecture says will be very useful for
    visualizing two dimensional matrices moving forward, and it is
    exactly how the face is drawn in Lecture 11 (added).

6. SHAPE
  - Every matrix has a property called shape that tells you its
    dimensions. It comes back as (rows, columns), the same order as
    Lecture 7's rule.
  - In the lecture the shape of the random matrix is whatever was
    asked for when it was built. Ask anyway when someone hands you
    a matrix you did not build.
  - Code (added):
      print(M.shape) ## (10, 15) for the random matrix above
      print(np.array([[5,1,7],[2,8,3]]).shape) ## (2, 3)
    No parentheses after shape. It is a property, not a function
    call (added).

7. INDEXING: ONE CELL, ONE COLUMN, ONE ROW
  - To read one number out of a matrix, index it with the row
    position and the column position inside one pair of square
    brackets, separated by a comma: M[row, column].
  - To get a whole column, ask for every row at a given column
    position with a colon in the row slot: M[:, column]. To get a
    whole row, put the colon in the column slot: M[row, :].
  - The lengths tell you which is which. In the lecture's 20 by 30
    example, a column comes back with length 20 because there are
    20 rows, and a row comes back with length 30 because there are
    30 columns.
  - NumPy counts positions from zero, so M[0,0] is the top left
    cell (added).
  - Example (added), with the 2 by 3 matrix M = [[5,1,7],[2,8,3]]:
      print(M[1,2]) ## row position 1, column position 2: 3
      print(M[:,1]) ## column position 1: [1 8], length 2
      print(M[0,:]) ## row position 0: [5 1 7], length 3
    The column has as many entries as there are rows. The row has
    as many entries as there are columns. Same rule as the lecture,
    smaller numbers.
  - Why this matters for the rest of the course (added): Lecture 7
    stores scatter points as a 2 by n matrix, so P[0,:] is every x
    value and P[1,:] is every y value. Lecture 10's eigenvector
    matrix is read by columns, eigvecs[:,0] and eigvecs[:,1].

8. EIGENVALUES AND EIGENVECTORS IN NUMPY
  - Lecture 9 computed eigenvalues and eigenvectors by hand. In
    NumPy it is one call. The linear algebra library has a function
    that returns both for a square matrix.
  - Code (added):
      import numpy as np
      M = np.array([[4,2],[1,3]]) ## the Lecture 9 worked example
      vals,vecs = np.linalg.eig(M) ## eigenvalues, eigenvector matrix
      print(vals) ## [5. 2.]
      print(vecs.round(4)) ## [[ 0.8944 -0.7071] [ 0.4472  0.7071]]
  - How to read the output: the first item is the list of
    eigenvalues. The second is a matrix where each column is a
    single eigenvector. The first column pairs with the first
    eigenvalue, the second column with the second.
  - So for this M, the eigenvector for 5 is the first column,
    (0.8944, 0.4472), and the eigenvector for 2 is the second
    column, (-0.7071, 0.7071).
  - Compare to Lecture 9 (added): by hand the eigenvector for 5 was
    (2, 1) and the eigenvector for 2 was (-1, 1). NumPy's columns
    point the same way. (2,1) divided by its length, sqrt(5), is
    (0.8944, 0.4472). (-1,1) divided by sqrt(2) is (-0.7071,
    0.7071). Same lines, different lengths, which is the next
    section.
  - Do not read the eigenvector matrix by rows (added). The rows
    mean nothing on their own. Columns only.

9. UNIT-LENGTH EIGENVECTORS
  - Remember from Lecture 9: for a given eigenvalue there are
    infinitely many eigenvectors, all with the same angle. NumPy
    has to give you one of them, and it chooses the one with unit
    length, norm equal to one.
  - The lecture verifies this by asking the linear algebra library
    for the norm of each column of the eigenvector matrix. Both
    norms come back as one.
  - Code (added):
      print(np.linalg.norm(vecs,axis=0)) ## [1. 1.], one norm per column
    axis=0 means "work down each column" (added). Without it, norm
    treats the whole matrix as one object and gives a single
    number.
  - Sign is NumPy's choice too (added). If a column comes back as
    (-0.8944, -0.4472) instead of (0.8944, 0.4472), it is the same
    eigenvector, pointing the other way along the same line.
    Lecture 8's definition allows that.

10. KEY TAKEAWAYS
  - np.array on a list of lists makes a matrix. Its type is
    numpy.ndarray, not list.
  - np.ones and np.zeros build filled matrices from a (rows,
    columns) tuple. Scalar times ones gives any constant matrix.
  - plt.imshow draws a matrix as a colored grid, plt.colorbar
    labels the colors.
  - M.shape is (rows, columns). M[r, c] is one cell, M[:, c] is a
    column of length rows, M[r, :] is a row of length columns.
  - np.linalg.eig returns eigenvalues and a matrix whose columns
    are the matching eigenvectors, each with norm one.

11. QUIZ-SAFE FACTS
  - Nested lists can represent matrices in native Python, but NumPy
    arrays are the better tool.
  - A NumPy matrix is built by wrapping a list of lists in
    np.array. Its type is numpy.ndarray.
  - NumPy has functions to create a matrix of ones or of zeros of a
    given size. A matrix of all fours is ones times the scalar 4.
  - Matplotlib's pyplot, aliased plt, is used throughout the
    course. imshow plots a matrix as a grid colored by value.
    colorbar shows which numbers the colors correspond to.
  - The lecture's random matrix is 20 by 30, filled with numbers
    drawn uniformly between zero and one.
  - shape is a property giving the dimensions of a matrix.
  - A column of a 20 by 30 matrix has length 20. A row has length
    30.
  - NumPy's linear algebra library has a function that returns
    eigenvalues and eigenvectors for a square matrix.
  - In the returned eigenvector matrix, each column is one
    eigenvector, matched by position to its eigenvalue.
  - NumPy returns the eigenvector with unit length, norm equal to
    one. The lecture verifies this with the norm function on each
    column.
